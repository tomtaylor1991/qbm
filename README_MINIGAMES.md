# Mini-game frissítés

Új funkciók:
- körvásárlás: sör- és töménykör, +50 személyes pont;
- félkarú rabló: 10 pontos beugró, 9 cserélhető PNG szimbólum;
- sorsolás: a jelenlévő kísérők közül egy túlélő kiválasztása;
- a korábbi PDF kalandlevél export is benne maradt, fekete betűszínnel.

## Slot képek

A saját képeidet ide másold, azonos fájlnévvel:

public/images/slot/slot-1.png
...
public/images/slot/slot-9.png

A csomagban helykitöltő képek vannak. Ajánlott: 256x256 px, átlátszó PNG.

## Szükséges npm csomagok

A PDF exporthoz:

npm install jspdf html2canvas

A mini-game-ek nem igényelnek új npm csomagot.
